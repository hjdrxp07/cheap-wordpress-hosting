## 便宜WordPress主机有两条路，先选路线再比价格

市面上叫「WordPress 主机」的产品其实分两类：托管型主机和 VPS 自建。托管型就是主机商把服务器环境、缓存、一键安装 WordPress 这些都给你配好，你登录后台就能建站；VPS 自建则是你租一台带独立 root 权限的服务器，自己装系统、装环境、装 WordPress，自由度最高，也最考验动手能力。

先选路线再比价格，顺序不能反。因为这两类产品的计费逻辑完全不同：托管型靠「首年超低价」拉新，第二年恢复原价；RackNerd 这类低价 VPS 则是常年按年付促销价卖，价格本身就很低，只是服务全靠自己。搞混了这两种便宜，很容易算错账。

全球四成左右的网站跑在 WordPress 上，围绕它的生态极其成熟，两条路线都能顺利建站，差别在于成本结构和你需要投入的时间。

**为什么首年那么便宜，第二年贵很多？**
行业惯例。托管型主机靠首年折扣拉新，续费才是正常价，所以下单前把「首期总价 + 每年续费价」都算进去。RackNerd 这类年付促销 VPS 的特点是续费价通常和首期接近，这也是两条路线长期成本差距的来源，具体以订单页标注为准。

**国外主机建 WordPress 要备案吗？**
不用。机房在美国、欧洲等海外地区的主机和 VPS 都免备案，开通就能用。需要权衡的是国内访问速度，选西海岸机房会好一些。如果网站主要面向国内用户且愿意走备案流程，可以考虑阿里云、腾讯云的云服务器或轻量应用服务器，它们的使用方式更接近 VPS，同样需要自己维护；国内的传统虚拟主机限制多，不推荐。

**免费主机和免费域名能用吗？**
不建议。免费主机通常伴随不稳定、广告和功能限制，免费域名（比如那些冷门后缀）经常被搜索引擎和邮箱服务商差别对待，折腾的成本比省下的钱高。域名一年几十元，主机按上面的路线选，才是真正的省钱方式。
